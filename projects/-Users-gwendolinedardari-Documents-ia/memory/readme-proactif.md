Quand une discussion clarifie quelque chose d'utile pour se servir du plugin ia-kit (installation, mise à jour, portées, fonctionnement d'un hook…), proposer tout de suite de l'ajouter au README du dépôt ia.

**Why:** le 2026-10-21, elle a dû demander trois fois « c'est dans le README ? » (hooks, commande de mise à jour, portées) ; à chaque fois ça manquait. Le hook README du dépôt ne voit que les fichiers modifiés, pas les explications données en conversation.

**How to apply:** proposer l'ajout en une phrase (où et quoi) dans la même réponse que l'explication ; écrire après son accord, puis demander pour le commit. Voir [[ia-kit-plugin]].
